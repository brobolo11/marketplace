## 🎯 ¿Qué es HouseFixes?

Plataforma web completa que conecta clientes con profesionales de servicios del hogar, permitiendo:

- **Clientes:** Buscar, contratar y pagar servicios profesionales
- **Profesionales:** Ofrecer servicios, gestionar reservas y emitir facturas
- **Administradores:** Supervisar toda la plataforma

---

## 💻 Tecnologías Utilizadas

- **Backend:** Laravel 12.35.0 (PHP 8.3.26)
- **Frontend:** Blade Templates + Tailwind CSS 3.4 + Alpine.js
- **Base de Datos:** MySQL 8.0
- **Autenticación:** Laravel Jetstream + Fortify
- **PDF:** barryvdh/laravel-dompdf v3.1.1

---

## ✨ Funcionalidades Principales

### 🔐 Sistema de Autenticación
- Registro y login seguro
- Autenticación de dos factores (2FA)
- 3 roles: Admin, Profesional, Cliente

### 🛠️ Gestión de Servicios
- Publicación de servicios con fotos
- Categorización (20+ categorías)
- Búsqueda y filtros avanzados
- Sistema de reseñas y ratings

### 📅 Sistema de Reservas
- Solicitud de servicios con fecha
- Aceptación/rechazo por profesional
- Estados: pending, accepted, rejected, completed, cancelled
- Historial completo

### 💳 Sistema de Pagos
- Checkout simulado profesional
- Gestión de transacciones
- Historial de pagos
- Comisión de plataforma (10%)

### 📄 Sistema de Facturas (★ NUEVO)
- **Generación automática de facturas**
- **PDFs profesionales descargables**
- **Numeración única (INV-YYYY-XXX)**
- **Cálculo automático de IVA (21%)**
- **Vista administrativa de todas las facturas**
- **Estadísticas de facturación**

### 💬 Mensajería
- Chat entre clientes y profesionales
- Marcar mensajes como leídos
- Historial de conversaciones

### ⏰ Gestión de Disponibilidad
- Horarios por día de semana
- Bloqueos específicos
- Validación automática

### 👨‍💼 Panel Administrativo
- Dashboard con estadísticas
- Gestión de usuarios (CRUD)
- Cambio de roles
- Supervisión de servicios y reservas
- Vista global de facturas
