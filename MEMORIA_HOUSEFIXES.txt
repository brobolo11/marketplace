1.1. Contexto y Motivación
--------------------------------------------------------------------------------

En la actualidad, la búsqueda de profesionales de servicios del hogar (fontaneros, 
electricistas, limpieza, carpinteros, etc.) es un proceso complejo y desorganizado. 
Los clientes deben confiar en recomendaciones de conocidos o buscar en múltiples 
plataformas sin garantías de calidad.

Principales problemas identificados:
- Dificultad para encontrar profesionales confiables cerca del domicilio
- Falta de transparencia en precios y disponibilidad
- Ausencia de sistemas de reseñas verificadas
- Procesos de pago inseguros o informales
- No existe un historial digitalizado de servicios contratados

Esta problemática motivó el desarrollo de HouseFixes, una solución integral que 
digitaliza el sector de servicios del hogar, conectando clientes y profesionales 
en una plataforma segura, transparente y fácil de usar.


1.2. Finalidad del Proyecto
--------------------------------------------------------------------------------

HouseFixes es una plataforma web tipo marketplace que tiene como finalidad:

Para CLIENTES:
- Buscar y comparar servicios profesionales por categoría y ubicación
- Reservar servicios seleccionando fecha y hora disponible
- Pagar de forma segura con historial de transacciones
- Dejar reseñas y valoraciones verificadas (solo tras completar el servicio)
- Descargar facturas en PDF de todos los servicios contratados
- Comunicarse directamente con los profesionales mediante chat

Para PROFESIONALES:
- Publicar servicios con descripción, precio y galería de fotos
- Gestionar disponibilidad horaria (por días de la semana y bloqueos específicos)
- Recibir y gestionar solicitudes de reserva (aceptar/rechazar)
- Generar facturas automáticas en PDF tras completar servicios
- Visualizar estadísticas de ingresos y servicios prestados
- Construir reputación mediante reseñas de clientes

Para ADMINISTRADORES:
- Supervisar toda la actividad de la plataforma
- Gestionar usuarios (cambio de roles, suspensión, eliminación)
- Gestionar categorías de servicios (CRUD completo)
- Acceder a todas las facturas del sistema con búsqueda avanzada
- Visualizar estadísticas globales en tiempo real
- Moderar contenido inapropiado


1.3. Objetivos del Proyecto
--------------------------------------------------------------------------------

OBJETIVO PRINCIPAL:
Desarrollar una plataforma web completa y funcional que digitalice el proceso 
de contratación de servicios del hogar, aplicando la arquitectura MVC con el 
framework Laravel.

OBJETIVOS ESPECÍFICOS:

1. Implementar un sistema de autenticación robusto con 3 roles diferenciados
   (administrador, profesional, cliente)

2. Crear un sistema completo de gestión de servicios con:
   - CRUD completo
   - Galería de fotos (hasta 5 por servicio)
   - Categorización
   - Búsqueda y filtros avanzados

3. Desarrollar un flujo de reservas con múltiples estados:
   - pending (pendiente de aceptación)
   - accepted (aceptada, pendiente de pago)
   - rejected (rechazada por profesional)
   - completed (servicio completado)
   - cancelled (cancelada)

4. Implementar un sistema de pagos simulado que incluya:
   - Checkout profesional
   - Historial de transacciones
   - Gestión de estados de pago
   - Comisión de plataforma (10%)

5. Crear un sistema innovador de facturación automática:
   - Generación de PDFs profesionales
   - Numeración única y secuencial (INV-YYYY-XXX)
   - Cálculo automático de IVA (21%)
   - Descarga para clientes y profesionales

6. Desarrollar un sistema de reseñas verificadas (solo tras servicio completado)

7. Implementar mensajería básica entre usuarios

8. Crear un panel administrativo completo con estadísticas

9. Diseñar una interfaz responsive moderna con Tailwind CSS

10. Aplicar buenas prácticas de desarrollo:
    - Código limpio y documentado
    - Base de datos normalizada
    - Seguridad (CSRF, XSS, SQL injection)
    - Control de versiones con Git

2.2. Requisitos Funcionales
--------------------------------------------------------------------------------

RF-01: Sistema de Autenticación
- El sistema debe permitir registro de usuarios con email y contraseña
- Debe soportar 3 roles: admin, professional, client
- Debe incluir recuperación de contraseña
- Debe permitir autenticación de dos factores (2FA)

RF-02: Gestión de Servicios
- Los profesionales deben poder crear servicios con: título, descripción,

RF-03: Búsqueda y Filtrado
- El sistema debe permitir buscar servicios por texto
- Debe permitir filtrar por categoría
- Debe mostrar el rating promedio de cada servicio
- Debe mostrar los servicios más recientes

RF-04: Sistema de Reservas
- Los clientes deben poder crear reservas indicando fecha y dirección
- Las reservas deben tener estado: pending, accepted, rejected, completed, cancelled
- Los profesionales deben poder aceptar o rechazar solicitudes
- Los profesionales deben poder completar servicios
- Los clientes y profesionales deben poder cancelar reservas

RF-05: Gestión de Disponibilidad
- Los profesionales deben poder configurar horarios por día de la semana
- Debe permitir crear múltiples franjas horarias por día
- Debe permitir crear bloqueos específicos (vacaciones)
- Debe validar solapamientos de horarios

RF-06: Sistema de Pagos
- El sistema debe simular un checkout profesional
- Debe calcular comisión de plataforma (10%)
- Debe generar ID de transacción único
- Debe mantener historial de pagos
- Debe permitir reembolsos

RF-07: Sistema de Facturas
- El sistema debe generar facturas automáticamente tras completar servicios
- Debe asignar numeración única (INV-YYYY-XXX)
- Debe generar PDF con diseño profesional
- Debe calcular IVA automáticamente (21%)

RF-08: Sistema de Reseñas
- Los clientes deben poder dejar reseñas solo tras completar servicios
- Debe incluir rating de 1-5 estrellas

RF-09: Sistema de Mensajería
- Debe permitir chat entre clientes y profesionales
- Debe marcar mensajes como leídos
- Debe mantener historial de conversaciones

RF-10: Panel Administrativo
- Los administradores deben poder ver dashboard con estadísticas
- Deben poder gestionar usuarios (CRUD, cambio de roles)
- Deben poder gestionar categorías (CRUD)
- Deben poder ver todas las facturas del sistema

RF-11: Notificaciones
- El sistema debe notificar nuevas solicitudes de reserva

RF-12: Dashboards Diferenciados

2.5. Arquitectura y Escalabilidad del Sistema
--------------------------------------------------------------------------------

ARQUITECTURA MODULAR:

HouseFixes está construido sobre una arquitectura modular basada en el patrón
MVC (Modelo-Vista-Controlador) de Laravel, lo que permite:

1. Separación de Responsabilidades:
   - Modelos: Lógica de negocio y acceso a datos
   - Vistas: Presentación e interfaz de usuario
   - Controladores: Coordinación entre modelos y vistas

2. Código Reutilizable:
   - Componentes Blade reutilizables (service-card, booking-card)
   - Middlewares compartidos para autorización
   - Traits para funcionalidades comunes

3. Fácil Mantenimiento:
   - Código organizado por funcionalidad
   - Convenciones de nomenclatura claras
   - Documentación inline en código crítico

ESCALABILIDAD HORIZONTAL Y VERTICAL:

ESCALABILIDAD DE BASE DE DATOS:
- Índices en columnas de búsqueda frecuente (user_id, service_id, status)
- Relaciones optimizadas con Eloquent ORM
- Preparado para implementar caché (Redis/Memcached)
- Posibilidad de migrar a cluster MySQL para alta disponibilidad

ESCALABILIDAD DE APLICACIÓN:
- Arquitectura stateless (sin estado en servidor)
- Sesiones almacenables en Redis/Database
- Assets compilados y versionados con Vite
- Preparado para CDN (Content Delivery Network) para archivos estáticos

ESCALABILIDAD DE FUNCIONALIDADES:
- Sistema de eventos permite añadir funcionalidades sin modificar código existente
- API REST preparada para futuras aplicaciones móviles
- Sistema de permisos granular permite añadir nuevos roles fácilmente
- Base de datos normalizada facilita nuevas tablas y relaciones

public function store(Request $request)
{
    $validated = $request->validate([
        'title' => 'required|string|max:255',
        'description' => 'required|string',
        'price_hour' => 'required|numeric|min:0',
        'category_id' => 'required|exists:categories,id',
        'photos.*' => 'image|mimes:jpeg,png,jpg|max:2048'
    ]);

    $service = Service::create([
        'user_id' => auth()->id(),
        'title' => $validated['title'],
        'description' => $validated['description'],
        'price_hour' => $validated['price_hour'],
        'category_id' => $validated['category_id'],
    ]);

    if ($request->hasFile('photos')) {
        foreach ($request->file('photos') as $photo) {
            $path = $photo->store('service_photos', 'public');
            ServicePhoto::create([
                'service_id' => $service->id,
                'photo_path' => $path,
            ]);
        }
    }

    return redirect()->route('services.show', $service)
        ->with('success', 'Servicio creado exitosamente');
}

public function accept(Booking $booking)
{
    if ($booking->pro_id !== auth()->id()) {
        abort(403);
    }

    if (!$booking->isPending()) {
        return back()->with('error', 'Esta reserva no puede ser aceptada');
    }

    $booking->accept();

    // Notificar al cliente
    Notification::create([
        'user_id' => $booking->user_id,
        'type' => 'booking_accepted',
        'title' => 'Reserva Aceptada',
        'message' => 'Tu reserva ha sido aceptada. Procede al pago.',
        'link' => route('payments.checkout', $booking->id),
    ]);

    return redirect()->route('bookings.pending-requests')
        ->with('success', 'Reserva aceptada correctamente');
}

public function processPayment(Request $request, Booking $booking)
{
    $validated = $request->validate([
        'payment_method' => 'required|in:credit_card,debit_card,paypal',
    ]);

    // Calcular comisión (10%)
    $amount = $booking->total_price;
    $platformFee = $amount * 0.10;
    $professionalAmount = $amount - $platformFee;

    // Generar ID de transacción único
    $transactionId = 'TXN-' . strtoupper(uniqid());

    // Crear pago
    $payment = Payment::create([
        'booking_id' => $booking->id,
        'user_id' => auth()->id(),
        'professional_id' => $booking->pro_id,
        'amount' => $amount,
        'platform_fee' => $platformFee,
        'professional_amount' => $professionalAmount,
        'payment_method' => $validated['payment_method'],
        'transaction_id' => $transactionId,
        'status' => 'completed',
        'paid_at' => now(),
    ]);

    // Actualizar reserva
    $booking->update(['paid_at' => now()]);

    // Notificar al profesional
    Notification::create([
        'user_id' => $booking->pro_id,
        'type' => 'payment_received',
        'title' => 'Pago Recibido',

public function generateInvoiceNumber(): string
{
    $year = date('Y');
    $lastInvoice = Invoice::whereYear('created_at', $year)
                          ->orderBy('id', 'desc')
                          ->first();
    
    $number = $lastInvoice ? 
              intval(substr($lastInvoice->invoice_number, -3)) + 1 : 1;
    
    return 'INV-' . $year . '-' . str_pad($number, 3, '0', STR_PAD_LEFT);
}

public function isPaid(): bool
{
    return $this->status === 'paid';
}

public function markAsPaid(): void
{
    $this->update(['status' => 'paid']);
}

CONTROLADOR - InvoiceController::generate():

public function generate(Booking $booking)
{
    // Verificar permisos
    if ($booking->pro_id !== auth()->id()) {
        abort(403);
    }

    // Verificar que el servicio esté completado
    if (!$booking->isCompleted()) {
        return back()->with('error', 
            'Solo puedes generar facturas de servicios completados');
    }

    // Verificar si ya existe factura
    if ($booking->invoice) {
        return redirect()->route('invoices.show', $booking->invoice);
    }

    // Crear factura
    $invoice = Invoice::create([
        'booking_id' => $booking->id,
        'invoice_number' => (new Invoice())->generateInvoiceNumber(),
        'issued_at' => now(),
        'total' => $booking->total_price,
        'status' => 'pending',
    ]);

    // Generar PDF
    $this->generatePDF($invoice);

    return redirect()->route('invoices.show', $invoice)
        ->with('success', 'Factura generada correctamente');
}

GENERACIÓN DE PDF - InvoiceController::generatePDF():

protected function generatePDF(Invoice $invoice)
{
    $booking = $invoice->booking;
    
    // Calcular IVA (21%)
    $subtotal = $booking->total_price / 1.21;
    $iva = $booking->total_price - $subtotal;
    
    $data = [
        'invoice' => $invoice,
        'booking' => $booking,
        'client' => $booking->client,
        'professional' => $booking->professional,
        'service' => $booking->service,
        'subtotal' => $subtotal,
        'iva' => $iva,
        'total' => $booking->total_price,
    ];
    
    $pdf = PDF::loadView('invoices.pdf', $data);
    $pdf->setPaper('A4', 'portrait');
    
    $filename = 'invoice_' . $invoice->invoice_number . '.pdf';
    $path = 'invoices/' . $filename;
    
    Storage::disk('public')->put($path, $pdf->output());
    
    $invoice->update(['pdf_path' => $path]);
}

public function store(Request $request, Booking $booking)
{
    // Verificar que el usuario es el cliente de la reserva
    if ($booking->user_id !== auth()->id()) {
        abort(403);
    }

    // Verificar que el servicio está completado
    if (!$booking->isCompleted()) {
        return back()->with('error', 
            'Solo puedes dejar reseñas de servicios completados');
    }

    // Verificar que no existe ya una reseña
    if ($booking->review) {
        return back()->with('error', 'Ya has dejado una reseña');
    }

    $validated = $request->validate([
        'rating' => 'required|integer|min:1|max:5',
        'comment' => 'nullable|string|max:1000',
    ]);

    Review::create([
        'booking_id' => $booking->id,
        'user_id' => auth()->id(),
        'service_id' => $booking->service_id,
        'rating' => $validated['rating'],
        'comment' => $validated['comment'],
    ]);

    return redirect()->route('bookings.show', $booking)
        ->with('success', 'Reseña publicada correctamente');
}

ANEXO B: INSTALACIÓN Y CONFIGURACIÓN
--------------------------------------------------------------------------------

REQUISITOS DEL SISTEMA:
- PHP >= 8.2
- MySQL >= 8.0
- Composer >= 2.6
- Node.js >= 18.x
- NPM >= 9.x

PASOS DE INSTALACIÓN:

1. Clonar el repositorio:
   git clone https://github.com/brobolo11/marketplace.git
   cd marketplace

2. Instalar dependencias PHP:
   composer install

3. Instalar dependencias JavaScript:
   npm install

4. Configurar archivo .env:
   cp .env.example .env
   php artisan key:generate

5. Configurar base de datos en .env:
   DB_DATABASE=housefixes
   DB_USERNAME=root
   DB_PASSWORD=

6. Ejecutar migraciones:
   php artisan migrate

7. Poblar base de datos:
   php artisan db:seed

8. Crear enlace simbólico para storage:
   php artisan storage:link

9. Compilar assets:
   npm run build

10. Iniciar servidor:
    php artisan serve
